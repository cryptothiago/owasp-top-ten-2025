# Security notice

This repository is intentionally vulnerable and is designed only for local security training.

- Do not deploy it to a public server.
- Do not place real credentials, tokens, customer data or production secrets in it.
- Keep the Docker port bound to `127.0.0.1`.
- Use only systems and data you own or are explicitly authorized to test.

The vulnerable routes are prefixed with `/vuln/`; corrected examples use `/fixed/`.
